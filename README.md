
```bash

```

**Expected Output:**

```text

```

**Note:** Programs that use browser-specific features such as `document`, `window`, or DOM manipulation should generally be run in a web browser using an HTML file. Node.js is intended for JavaScript execution outside the browser and does not provide the browser DOM by default.

## 📋 Sample Program

### Check Even or Odd Number

**Program:** `CheckEven.js`

```javascript
const readline = require("node:readline");

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

rl.question("Enter a number: ", (input) => {
    const num = Number(input);

    if (input.trim() === "" || !Number.isFinite(num)) {
        console.log("Please enter a valid number.");
    } else if (num % 2 === 0) {
        console.log("It is Even");
    } else {
        console.log("It is Odd");
    }

    rl.close();
});
```

**Run the Program:**

```bash
node CheckEven.js
```

**Sample Output:**

```text
Enter a number: 10
It is Even
```
